# Interview Talk Track

## 30-second version

I built a synthetic B2B supply-chain data-operations project to understand the transaction flows behind distributor networks. The project models purchase orders, acknowledgments, shipment notices, invoices, and file-transfer events across suppliers and distributors. I used SQL and Python to detect missing documents, rejected transactions, late shipments, invoice mismatches, and transfer failures, then created a partner scorecard and troubleshooting runbook to show how I would prioritize and resolve operational data issues.

## What this demonstrates

- Business-process understanding, not just dashboarding
- SQL-based root-cause analysis
- Data validation and exception management
- B2B partner and account thinking
- Operational prioritization and resource allocation
- Documentation and repeatable troubleshooting
- Ability to learn EDI-adjacent workflows without claiming production X12 expertise

## Honest boundary

This is a portfolio simulation using synthetic data. The EDI-like samples are simplified training representations, not production ANSI X12 documents, and the project is not affiliated with AFFLINK or Performance Food Group.
